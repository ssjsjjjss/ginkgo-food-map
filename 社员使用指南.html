一、这到底是什么

1.1 一句话

一个社团自己的成都觅食地图。地图上每个「杯子」是一家店，杯子越大说明大家打分越高。下次不知道吃什么，打开看一眼。

1.2 它不是什么（先说清楚，免得误会）

  • 不是大众点评，不是商业榜单，不接推广、不收钱、不排名收费
  • 不是官方数据，所有分数都是社员自己打的，错了就靠大家再打一次纠正
  • 不是私人日记：你写的东西所有人都能看到
  • 不是匿名保险箱：虽然不要求写真名，但评价是公开的

1.3 数据放在哪（理解了这个，后面同步那节就全懂了）

所有人的评价、店铺、照片，都存在社团的服务器上，全世界只有一份。

你的手机/电脑里也有一份临时副本（为了让离线也能打开），但它只是副本。 所以：

  • 你在手机上写的评价，电脑上刷新一下就有了，不需要你传
  • 你在这台设备删掉的东西，服务器上也删了，别人也看不到了（所以删除要慎重）
  • 反过来，换设备不会丢数据，因为数据本来就不在你的设备上

1.4 为什么这个分数值得信

  1. 分数是算出来的，不是谁填的：一家店的分数 = 所有社员给它打的分的算术平均
  2. 没有"改分数"的按钮：管理员也只能删掉某条评价，不能直接改一家店的分数
  3. 删了也能恢复：删除是"软删除"，管理员可以一键恢复
  4. 改了会留痕：每条评价都有 updated_at，冲突时以时间新的为准

换句话说：想让一家店升杯，唯一的办法是真的好吃 + 大家真去打分。

1.5 隐私与安全边界

项目情况

要不要登录不用。开启社员口令后，填一次口令就行（见第六节）

二、装到桌面 / 主屏幕（可选，但很香）

2.1 装了有什么好处

  • 桌面 / 主屏幕上多一个图标，点开就是 App 的样子（全屏、没有地址栏）
  • 打开更快，弱网时也不容易白屏
  • 会自动更新，永远是最新版，不用重新下载

不装也完全能用。直接用浏览器打开链接，功能一模一样。

2.2 怎么装

安卓（Chrome / Edge / 夸克等）

  1. 用浏览器打开网址
  2. 右上角 ⋮ 菜单
  3. 「添加到主屏幕」或「安装应用」

电脑（Windows / Mac，Chrome 或 Edge）

  1. 打开网址
  2. 地址栏最右边有个安装图标（⊕ 或小显示器形状），点它

—— 或者菜单 → 「安装 Ginkgo 美食地图…」

  1. 之后开始菜单 / 程序坞里就有独立图标了

iPhone / iPad（Safari）

  1. 必须用 Safari 打开（Chrome 版 iOS 不支持装）
  2. 底部中间的分享按钮 → 往下找「添加到主屏幕」

2.3 装了之后想卸掉

  • 电脑：Chrome/Edge 里打开它 → 地址栏右侧安装图标 → 「卸载」；或在系统里当普通软件卸
  • 手机：长按图标 → 移除 / 删除（跟删普通 App 一样，不会影响你的数据，数据在服务器上）

2.4 装了以后打开是旧界面 / 白屏

  • 先下拉刷新或杀掉重开
  • 还不行：卸掉重装一次（数据不受影响）
  • 极少数情况是浏览器缓存了旧版，重装就好

四、看懂评分

4.1 四个维度，各 0–10 分（可以拖到半分）

维度到底看什么打分时问自己
味道好不好吃"吃完想不想再来一次？"
性价比这个价钱值不值"同样这笔钱，成都能不能有更好的选择？"
服务态度、上菜速度"叫了半天没人理吗？上菜等了多久？"
环境干净、拥挤、吵闹"能不能坐下来好好吃顿饭、说说话？"

四个维度是分开算再平均的。一家很好吃但脏得离谱的苍蝇馆子，味道 9 分、环境 3 分，

平均下来是 6 分——这就是它真实的样子。别只按味道打一个总分。

4.2 打分锚点（建议，不是硬性规定）

为了让大家的 7 分都差不多是同一个意思，参考这张表：

分数味道性价比服务环境
9–10会专门跑一趟，会安利给朋友便宜到不敢相信主动、热情、有分寸干净舒服，愿意久坐
7–8好吃，下次还来这个价很合理响应及时，有礼貌干净，正常
5–6能吃，不惊艳也不难吃一般，谈不上值不值叫得到人，不冷不热凑合，有点挤/有点吵
3–4难吃，但还能咽下去偏贵慢、爱搭不理脏、挤、吵，吃完想走
0–2吃一口就放下了明显被宰态度恶劣卫生状况不能接受

4.3 分数怎么算出来

一条评价的分数 = (味道 + 性价比 + 服务 + 环境) ÷ 4
一家店的分数   = 所有人给它打的分 ÷ 评价条数

举例：一家店现在有 3 条评价，平均 7.0 分（大杯）。 你吃得很满意，打了 9 分 → 新平均分 = (7.0×3 + 9) ÷ 4 = 7.5 → 升到超大杯。

反过来：一家店 4 条评价平均 8.0（超大杯），你觉得不行打了 4 分 → (8.0×4 + 4) ÷ 5 = 7.2 → 掉回大杯。

一条评价就能改变杯型，尤其是评价数还少的时候。 所以请认真打。

4.4 五档杯型

杯型平均分含义
🍗 全家桶≥ 8.6神店，冲
🥤 超大杯7.4 – 8.59强推
🥤 大杯6.2 – 7.39值得一去
🥤 中杯5.0 – 6.19中规中矩
🥤 小杯< 5.0踩雷预警
  • 杯子的大小和颜色都跟着档位变，地图上一眼就能分辨
  • 还没有人打分的店显示 「待评级」 —— 等着第一个吃的人，去当这个勇士
  • 评价数越少，分数越"飘"。只有 1 条评价的 9 分，不如 10 条评价的 8 分可信

五、怎么用

5.1 写一条评价（30 秒）

  1. 点地图上的杯子，或点左侧的店名卡片
  2. 右侧弹出详情 → 点 「写评价」
  3. 拖四个滑杆（0–10，能拖到半分）
  4. 拖动时上方会实时告诉你三件事：
  • 你这条是多少分
  • 这家店现在是什么杯型
  • 加上你这条之后会变成什么杯型 —— 想拉它一把还是踩它一脚，看着这个调
  1. 选 推荐 / 不推荐
  2. 填昵称（填一次这台设备就记住了，下次自动带出）和正文（至少 5 个字，最多 500 字）
  3. 可选：配 最多 2 张照片
  4. 提交 —— 这家店的杯型立刻重算

5.2 什么样的评价算"好评价"

有用的（大家能拿来决策）：

三刷了。推荐麻辣牛肉和脑花，脑花很嫩完全不腥。两个人点了 5 个菜 128，人均 64。

缺点：晚上 7 点后要排队 40 分钟，建议 6 点前去。环境吵，说话得喊。

  • 说了点了什么（具体菜品）
  • 说了花了多少（人均/总价）
  • 说了什么时候去的、要等多久（时效性）
  • 好和不好都说了

没用的（等于没写）：

挺好吃的，推荐。

还行吧

一般般，不会再去（为什么？）

判断标准就一句：别人看完这条，能不能决定去不去、点什么、什么时候去。

5.3 加一家新店

  1. 右上角 「添加餐厅」
  2. 顶部搜索框输入店名，会出现三种情况：
搜到的结果怎么办
只有一家自动选中，店名/地址/坐标一次填好，直接往下填
有好几家同名列出候选，每条都带地址，看清地址点一个
什么都搜不到别慌，见下面"搜不到怎么办"

小技巧：带上路名更准。 搜 建设路海吃牛鲜 比搜 海吃牛鲜 准得多。

搜不到怎么办（两步兜底）

  1. 输入路名，比如 玉林四巷、建设路，地图会跳到那条路（系统会自动按成都市找）
  2. 再点 「在地图上点选位置」，把位置精确到门口
  3. 店名、分类、人均自己填

注意：只输入路名（如 建设路）时，路名不会被当成店名存进去，

系统会等你补店名——所以别忘了填。

  1. 填人均：点档位（15 内 / 15–30 / 30–50 / 50–80 / 80–120 / 120–200 / 200–500 / 500–1000 / 1000+），

也可以直接输入具体数字（比如 68），页面上就直接显示 ¥68

  1. 填分类（火锅/川菜/面馆/小吃/烧烤/食堂/快餐/其他）和标签（可选，多个用逗号隔开）
  2. 保存 —— 地图上立刻多一个杯子

5.4 编辑 / 补充已有店铺

详情页 → 「编辑店铺」：

  • 补人均（显示"人均待补"的店，就是当初没填）
  • 改地址、分类、标签
  • 位置标错了也可以拖着改

谁都能编辑店铺信息，这是故意的——信息有时效性，看到错了直接改，比等人强。

但别改别人的评价（改不了，只能回复或让管理员删）。

5.5 删除店铺 / 删除评价

  • 自己加的店、自己写的评价：详情页会显示「删除」
  • 别人的：连删除按钮都不显示
  • 删除是软删除：从列表里消失，但服务器还留着，管理员能恢复
  • 删掉一条评价后，这家店的分数会立刻重算——所以删自己的差评，等于给这家店升分，请诚实

5.6 在别人的评价下面回复

每条评价下面都有 「回复」：点它 → 输入 → 回车发送。

什么时候该回复，而不是另开一条评价：

  • "上次去已经换厨师了" —— 补充时效性
  • "周六晚上要排 40 分钟" —— 补充信息
  • "我也去过，确实不错" —— 声援，让这条更有分量
  • "涨价了，现在人均 80" —— 纠正

回复不参与评分计算，不会改变分数。想改变分数就得自己写一条评价。

5.7 找店、看排名、看贡献榜

想干啥用哪个
看最好的店右上角 排行榜 —— 按杯型分档，每档前 3 名，点一下直接跳到那家店
看谁贡献最多右上角 贡献榜 —— 见 5.8
只看某一档左侧杯型胶囊，或地图左下角的图例（点一下筛选，再点取消）
找特定一家左侧搜索框（店名 / 地址 / 标签 / 分类）
按某个维度排左侧排序下拉：综合 / 味道 / 性价比 / 服务 / 环境 / 评价数 / 人均
只看推荐或只看踩雷左侧视图下拉

5.8 贡献榜（看看谁贡献最多）

右上角 「贡献榜」 —— 排行榜看的是店，贡献榜看的是人。

每行长这样：🥇 iyooo 36 条评价 · 31 家店 · 0 条回复

  • 排序第一关键字就是「评价条数」，加店数和回复数是附加展示（评价数相同时才比）
  • 前三名有 🥇🥈🥉；你自己那一行会高亮并标「（我）」
  • 没进前十也有贡献的话，末尾会单独补一行「第 N 名 · …（我）」

两条口径，先说清楚：

  1. 只统计填了昵称的内容。 匿名（显示「匿名社员」）的评价、店铺、回复都不计入。

所以写评价时一定要填昵称，否则写了也不上榜——昵称填一次这台设备就记住了。

  1. 按昵称统计，不按设备。 你在手机和电脑上用同一个昵称，会算作同一个人（这是好事）；

但两个恰好重名的人会被合并成一行。

已经写了匿名评价的没法补救，匿名评价不参与统计。之后写新的填上昵称就行。

六、社员口令（防外人刷分）

6.1 为什么要有这个

链接一旦转发到社团外，理论上任何人都能打开打分。开启社员口令之后，没口令的人只能看，写不了。

  • 没填口令 → 看得到全部内容，但写评价、加店的按钮点了会提示需要口令
  • 填过一次 → 这台设备就记住了，之后正常用，不用每次填

6.2 怎么填

  1. 右上角 「评分说明」（问号按钮）
  2. 拉到最下面 → 「社团口令」
  3. 输入口令 → 点 「保存」

口令由社团管理人员在群里发布。

6.3 什么时候需要重新填

  • 换了一台设备（手机 → 电脑，或换手机）
  • 清了浏览器数据 / 缓存
  • 换了浏览器
  • 社团改了口令（换届时）

口令是按设备存的，不是按人。所以你有三台设备，就要填三次。

6.4 忘了 / 填了还是写不了

  1. 先确认填的是最新的口令（换届后会换）
  2. 重新填一次：评分说明 → 社团口令 → 清除 → 重新输入 → 保存
  3. 还不行 → 群里问一声，别自己在那儿试半天

七、换设备 / 多设备同步（★ 最常见的问题）

7.1 结论先行

能。社员自己就能把一台设备的内容同步到自己的另一台设备，不需要管理员，不需要导文件，不需要做任何操作。

因为（回到第一节）数据本来就在服务器上，不在你的设备上。 新设备打开链接 → 自动从服务器拉全部店铺、评价、照片 → 十几秒就齐了。

7.2 新设备接入（标准四步，两分钟）

  1. 在新设备上打开链接：

https://ginkgo-food-map.app.workbuddy.host/?sharecode=YOUR_SHARECODE

  1. 等十几秒，看左上角状态条变成 ✓ 已同步到云端

（第一次会一次性拉全部内容，稍慢一点是正常的）

  1. 数一下：店铺数、评价数跟老设备一样，就说明齐了
  2. 如果社团开了口令 → 「评分说明」→ 社团口令 → 填一次 → 保存
  3. 完事。顺手按第二节装上桌面图标

就这些。没有"导出 → 传文件 → 导入"这回事。

7.3 什么能同步，什么不能（一张表说清）

内容能不能跨设备说明
店铺✅ 自动谁加的都同步
评价 + 四个维度的分✅ 自动
评价里的照片✅ 自动联网时随评价一起下来
评价下面的回复✅ 自动
人均、分类、标签✅ 自动
删除状态✅ 自动删了大家就都看不到了
昵称❌ 每台设备独立新设备上第一次写评价时重填一次，之后记住
社团口令❌ 每台设备独立新设备要重新填一次
管理员登录状态❌ 每台设备独立7 天有效期，换设备要重新登录
删除权❌ 跟设备绑定见 7.5，这是目前唯一的坑

7.4 唯一会卡住的情况：老设备上的内容还没传上去

如果老设备上的内容是在断网时写的、一直没成功上传，那它就只躺在老设备的浏览器里， 服务器上没有 —— 新设备自然也拉不到。

怎么判断：看老设备的状态条。

老设备状态条含义怎么办
✓ 已同步到云端早就传上去了新设备直接打开就有，不用管
离线模式，改动已暂存断网中，改动存在本机排队让老设备连上网、打开页面、等它变绿，新设备再刷新
云端同步失败，已回退本地服务器/网络有问题同上，联网后会自动补传；一直不行就群里报告

要点：只要老设备联网、页面开着、状态条变绿，它排队的东西就会自动传上去。 传完之后，新设备刷新就能看到，不用手动导。

7.5 目前唯一的坑：换设备后，管不了自己以前写的评价

系统判断"这条是你写的"，靠的是你这台浏览器里的一串设备 ID（自动生成，你看不见）。 所以：

  • 在老设备上：你写的评价有「删除」按钮
  • 在新设备上：那些评价不显示删除按钮（因为新设备是另一个 ID）

想删以前在别的设备上写的评价 → 找管理员帮忙删（管理员能删任何人的）。

这是已知限制。不影响查看、不影响继续写评价，只影响"跨设备管理自己旧内容"。

如果需要，可以后续给社员加一个「身份迁移」功能（老设备生成一个码，新设备输入一次，

删除权就跟着你走）—— 有需要就在群里提。

7.6 手动导出 / 导入 JSON（特殊情况下才用，且要懂限制）

什么时候用：

  • 你想给社团留一份本地存档
  • 两台设备完全不能联网、只能靠文件搬运

怎么做：

  1. 老设备：数据管理 → JSON 备份 → 导出 JSON 快照（要管理员口令）
  2. 把 .json 文件传到新设备（微信 / QQ / U 盘都行）
  3. 新设备：数据管理 → JSON 备份 → 导入 JSON 文件

导入的规则：

  • 按 id 去重，不会重复添加同一家店/同一条评价
  • 同一条记录冲突时，时间更新的那个赢

⚠️ 重要限制：JSON 快照不含照片本身。

照片是二进制，导进 JSON 里会让文件巨大，所以快照里只有文字和分数。

因此：别把 JSON 导入当成唯一的备份或迁移手段，照片会丢。

照片要跨设备，只能走 7.2 的联网自动同步。

7.7 常见误解澄清

误解事实
"我在手机上写的，电脑上要重新写一遍"不用。联网就自动有了
"换手机数据会没"不会。数据在服务器上
"我要把文件发给同学他才能看到"不用。他打开链接就有
"清理浏览器缓存会删掉大家的评价"不会。清的是你本机的副本，服务器上那份还在
"我在一台设备上清空全部数据，能把大家的评价都删掉"错，反过来。它只清你本机的副本，服务器上那份还在，下次同步又会全部回来（所以别拿它当"删库"）
"想让所有人都看不到某条评价"只能管理员删（或由作者本人删）。普通社员没有这个能力

八、社区规范

这个榜单的可信度完全靠大家自觉。它不是法律，是常识。

8.1 打分的原则

  • 只打自己真实吃过的。没去过就打分，是在污染所有人的数据
  • 四个维度分开想，别只按味道打个总分
  • 别因为老板是熟人打高分，也别因为跟老板吵过架打低分
  • 同一家店别反复打分刷。想吃第二次就再写一条新的（这没问题），但别为了拉分数连写五条
  • 涨价了、换厨师了、关门了 —— 回来更新一条。信息有时效性，去年的 9 分今年可能只值 5 分

8.2 正文的写法

该写：点了什么菜、花了多少、什么时候去的、等了多久、好在哪/差在哪、适合几个人去

别写：纯情绪（"绝了！！！"）、纯吐槽没有理由、与这家店无关的内容

照片：

  • 拍菜品和环境，别拍人
  • 最多 2 张，系统会自动压缩（长边 1200px、单张 200KB 以内）
  • 有同学入镜的话，先问过再发

8.3 禁止的事

❌说明
刷分一个人开小号、反复给同一家店打分
恶意差评因为私人恩怨打低分，或因为亲戚关系打高分
人身攻击在评价里骂同学、骂老板、挂人
商业推广给自家店 / 赞助商刷好评；发广告；拉踩同行
灌水刷屏无意义内容、重复内容、与美食无关的东西
泄露隐私在评价里写同学的真实姓名、学号、手机号

8.4 违规怎么处理（管理员执行）

  1. 第一次：删除违规内容，保留你其它正常的评价
  2. 反复：删除其全部评价
  3. 恶意刷分 / 攻击他人：删除内容 + 开启社员口令后不再发新口令（等于停止写入权限）

处理不是目的。真有争议，群里说，或者找管理员。别在评价区吵起来。

九、常见问题

关于评价

Q：我写的评价别人能看到吗？ 能。联网的话十几秒内就同步给所有人，不需要你点任何东西。

Q：为什么我的评价不见了？ 先刷新。还没有的话，可能是被管理员删了 —— 删除是软删除，能恢复。群里问一声就行。

Q：能删/改别人的评价吗？ 不能。别人的评价连删除按钮都不显示。你只能回复它，或者找管理员。

Q：能改自己已经写了的评价吗？ 不能直接改。最简单的办法：删掉重写一条（自己写的能删）。

Q：评价提交失败 / 提示需要口令？ 社团开了社员口令而你这台设备没填 → 「评分说明」→ 拉到最下面填一次。

Q：为什么我打了 10 分，这家店没变成全家桶？ 分数是所有人的平均。这家店以前只有 5.5 分、有 8 条评价，你一条 10 分拉不动多少。 —— 这恰恰说明这个榜单不容易被一个人带偏。

Q：评价数少的店分数可信吗？ 只有 1–2 条评价时，分数会很飘。评价数本身就是可信度，看排行榜时注意那个"N 评"。

关于加店

Q：人均显示"人均待补"？ 加店时没填。详情页「编辑店铺」可以补上（可以填具体数字，比如 68）。

Q：店名搜不到怎么办？ 见 5.3：先搜路名跳过去，再点「在地图上点选位置」精确到门口，店名自己填。

Q：搜出来的店地址不对？ 保存前看清候选列表里的地址；保存后可以在「编辑店铺」里改，位置也能拖。

Q：加错店了能删吗？ 自己加的店，详情页有「删除」。别人的店删不了（也没有删除按钮），找管理员。

关于地图和搜索

Q：地图是空的 / 白屏？ 需要联网加载。检查网络，或者下拉刷新。

Q：搜店名一直没结果？ 搜索用的是地图服务，搜索挂了地图照样能看（只是不能搜）。告诉管理员，可能是地图服务的密钥到期了。

Q：为什么地图定位偏了？ 手机定位本身有几米到几十米误差，正常。加店时建议用搜索定位或手动点选。

关于同步和设备

Q：换手机了，我以前写的评价还在吗？ 在。新手机打开链接就都有了。

Q：换手机了，还能删我以前写的评价吗？ 不能（见 7.5）。找管理员帮忙。

Q：我写了评价，别人说看不到？ 先看你自己的状态条是不是 ✓ 已同步到云端。 如果是"离线模式"或"同步失败"，说明还没传上去 —— 联网后打开页面等它变绿。

Q：照片会同步吗？ 会，联网时自动同步。两个限制：每条最多 2 张； 如果一条评价的照片总量超过 400KB，系统会只传文字不传照片（防止整条推送被拒）。 所以照片尽量拍完别太大，一般手机拍的正常照片压完都没问题。

Q：我在两台设备上同时改，会冲突吗？ 会有一点点：同一条记录，时间更新的那个赢。社团这个体量基本不会遇到。

Q：清浏览器数据会不会删掉大家的数据？ 不会。清的是你本机的副本。但会清掉你这台设备的社团口令，要重填一次。

Q：我在自己设备上点「清空全部数据」，会怎样？ 只清掉你这台设备的本地副本。服务器上那份还在，下次同步（刷新一下、或等一轮自动同步） 内容又会全部回来。所以它既删不掉大家的数据，也没法当"一键格式化"用—— 真要删，只能管理员删，或者你自己删自己写的那些。

关于权限

Q：数据管理 / 导入 CSV 为什么点不开？ 需要管理员口令。这是为了防止外人乱导入、乱清数据。社员用不到这些功能。

Q：我能当管理员吗？ 找社长。管理员口令是社团内部的，不发在群里。

十、出问题了找谁

情况找谁
不会用、有疑问社团群里直接问
口令忘了 / 填了没用群里问，或私聊管理员
发现有人刷分 / 违规内容私聊管理员，别在评价区吵
地图搜不了 / 页面报错群里说一声（附截图更好）
想加功能 / 有想法群里提，或者私聊维护的同学

这是给大家用的工具。用得顺手、信息靠谱，它才有存在的意义。 看到错了就改，吃到好的就写 —— 靠的就是每个人多花那 30 秒。
